## 2026-10-15 HTTPS与登录兼容修复

新增真实浏览器回归覆盖缺少UUID方法时的登录、退出和错误口令反馈。前端36项测试、类型检查、生产构建及格式验证通过；Python检查52项中36项实际通过、16项外部环境用例在本地跳过，后者由CI显式运行。
